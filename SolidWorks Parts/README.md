# SolidWorks Parts

All CAD for the arm lives here and is shared through GitHub, like the code. **One folder per assembly** (since Nov 12):

```
SolidWorks Parts/
  Arm/           Arm.SLDASM (the whole arm) + Shoulder Bracket, Upper Arm, Crank, Rod,
                 Forearm, Elbow Spacer, Wrist Bracket. Generated by tools/cad/build_arm.py,
                 except Shoulder Bracket (built by hand by Vyom, D18).
  Gripper/       Gripper.SLDASM + Body, Pinion, Rack (print 2), Fingers, Thumb.
                 Generated by tools/cad/build_gripper.py (D17).
  Base/          Siddharth's base enclosure + turntable (to come; Enclosure.SLDPRT moves here)
  Test Prints/   test pieces for print clearances (batch A); throwaway, not part of the arm
  STL/           print files exported from the parts above (batch B and reprints)
```

Arm.SLDASM uses ../Gripper/Gripper.SLDASM. SolidWorks finds parts through their **relative path**
from the assembly, so this works on any clone of the repo as long as the folders keep these names:
tested Nov 12 by copying the folder elsewhere and opening Arm.SLDASM from the copy (all 14 parts
loaded from the copy, none from the original).

## Rules

- **Keep each part in its assembly's folder, and never rename or move a part on its own.** The assemblies find parts by relative path; a renamed or moved part shows up as missing. If a part has to move, regenerate the assembly (scripted ones: re-run the script) or use SolidWorks' Pack and Go.
- **Script-generated parts: change the script, not the part.** Edit the parameters at the top of `tools/cad/build_arm.py` / `build_gripper.py` and re-run; edits made by hand in SolidWorks are overwritten by the next run.
- **Never rename a part to make a new version** (no `_v2`). Git already keeps every version: change the file, commit it, and say what changed in the commit message.
- **One person edits a file at a time.** SolidWorks files are binary, so git can't merge two people's changes; one person's work would be lost. Say in the group chat before editing a part someone else owns, and pull first.
- **Pull before you open, push when you're done:** `git pull` → edit → save → commit → push (through a pull request, like code).
- **Export STLs in millimetres, resolution Fine,** into `STL/`. Re-export after every change, so the STL never lags behind the part.
- Lock files (`~$*.SLDPRT`) and backups (`*.SLDBAK`) are ignored by git; don't force-add them.
